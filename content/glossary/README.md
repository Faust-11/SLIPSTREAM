# Словник термінів — формат

Одне джерело термінів для сторінки «Новачкам» (`/newbie#g-<id>`) і спливаючих підказок в історіях та таблицях гонок (фаза 5b).
Перевірка: `python3 scripts/content/check_glossary.py` (також у CI).

## terms.json

```jsonc
{
  "checked": "2026-11-15",                 // дата перевірки визначень
  "sources": [ { "id": "s15", "title": "F1 Glossary A–E", "publisher": "Formula1.com", "date": "…", "url": "https://…",
                 "kind": "primary | secondary", "lang": "en" } ],
  "terms": [
    {
      "id": "undercut",                    // kebab-case, унікальний; якір /newbie#g-undercut
      "auto": true,                        // true — рушій сам позначає першу появу за формами слова
      "uk": { "term": "Андеркат", "def": "…", "forms": ["андеркат*"] },
      "en": { "term": "Undercut", "def": "…", "forms": ["undercut*"] },
      "orig": "Undercut",                  // оригінал англійською (показується біля української назви)
      "sources": ["s19", "s29"]            // ≥ 1 джерело зі списку sources
    }
  ]
}
```

- **Форми слова:** `*` — до 5 літер закінчення (`поул*` → поул, поулу, поулом), пробіл — будь-які пробіли. Форма з великими
  літерами (`DRS`, `VSC`) або з `=` на початку (`=pole` — не «the Pole», національність) — з урахуванням регістру, решта — без. Межі слова: дефіс і апостроф теж межа не є
  (`поул*` не зачепить «поул-позицію» — для неї окрема форма).
- **Багатозначні терміни** («склад», «бокси», «шпилька», «кругові», «сліпстрім» — назва сайту) — `auto: false`; у тексті історії лише
  ручна мітка `[[t:<id>|видимий текст]]` (рішення користувача 15.11: «авто + винятки»). Ручні мітки — однакові в uk.md і en.md.
- Підказка — лише **перша поява** терміна на сторінці; заголовки глав і цитати не позначаються.
- Знімок усіх автоматичних знахідок у 33 історіях — `src/lib/glossary/__tests__/__snapshots__/` (переглядати після правок форм).
- Вікіпедія й її дзеркала — не джерело.
