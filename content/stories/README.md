# Історії — формат контенту

Розділ «Історії» (фаза 5). Тексти лежать у репозиторії; рушій сторінки (фаза 5) і адмінка (фаза 7) читають ці файли.
Рішення користувача 15.11: перевірка як у макетах «Сузука-1989 / Херес-1997 / Сінгапур-2008» (кожна цифра, дата й цитата —
з виноскою на джерело і статусом), дві мови (оригінал — українська, переклад — англійська), рубрики: скандали, сенсації,
розбори «як влаштовано», технічні революції.

## Структура

```
content/stories/<slug>/
  story.json   — метадані, джерела, твердження зі статусами
  uk.md        — текст українською (оригінал)
  en.md        — переклад англійською (ті самі виноски)
```

`slug` — латиниця, дефіси: `spygate-2007`, `f1-car-cost`.

### story.json

```json
{
  "slug": "spygate-2007",
  "category": "scandal",            // scandal | sensation | explainer | tech | history
  "years": [2007],                  // роки, про які історія (для фільтра й посилань на сезони)
  "title": { "uk": "…", "en": "…" },
  "dek":   { "uk": "…", "en": "…" },// лід, 1–2 речення
  "links": {                         // сторінки сайту, на які варто послатися (id з бази; необов'язково)
    "seasons": [2007], "races": ["2007/17"], "drivers": ["hamilton"], "teams": ["mclaren"], "circuits": ["monza"],
    "stories": ["abu-dhabi-2021"]   // пов'язані історії (slug)
  },
  "checked": "2026-11-15",          // дата перевірки джерел
  "sources": [
    { "id": "s1", "title": "…", "publisher": "FIA", "date": "2007-09-13", "url": "https://…", "kind": "primary", "lang": "en" }
  ],
  "claims": [
    { "id": "c1", "text": "Коротко, що стверджуємо (укр.)", "sources": ["s1", "s4"], "status": "ok" },
    { "id": "c2", "text": "…", "sources": ["s2"], "status": "one" },
    { "id": "c3", "text": "…", "sources": ["s3", "s5"], "status": "dis", "note": "s3 каже X, s5 — Y" }
  ]
}
```

- `kind`: `primary` (документ FIA/суду/команди, офіційний протокол, пряме інтерв'ю учасника, звіт того часу) або `secondary`.
- `status`:
  - `ok` — щонайменше **два незалежні** джерела (два передруки однієї агенції — одне джерело);
  - `one` — одне джерело (у тексті без натяку на сумнів, але читач бачить позначку);
  - `dis` — джерела розходяться; у `note` — у чому саме, у тексті — обидві версії.

### uk.md / en.md

Markdown без frontmatter. Кожне фактичне речення (цифра, дата, ім'я в ролі, цитата, «перший/єдиний») закінчується виноскою на
твердження: `… $100 млн.[^c4]`. Ті самі `c…` в обох мовах. Підзаголовки — `##`. Цитата — `>` з виноскою; цитату, перекладену
нами, позначати «(переклад Slipstream)» / в en оригінал англійською.

### Необов'язкові поля (фаза 5)

```jsonc
"featured": true,                                  // велика картка на сторінці списку (одна історія)
"kicker": { "uk": "Суперництво", "en": "Rivalry" },// штамп замість назви рубрики
"race": "1989/15",                                 // гонка для фактів банера (інакше links.races[0])
"blocks": [ { "id": "b1", "type": "…" } ]          // віджети даних, ставляться в тексті рядком [[block:b1]] (рушій — пізніше)
```

- `sources[].author` — автор статті (необов'язково).
- Для кожного твердження зі статусом `dis` — обов'язково `label {uk,en}` (коротка назва суперечки: «Коло зіткнення») і
  `reader {uk,en}` (пояснення для читача: що каже яке джерело, без внутрішніх id на кшталт s3). `note` лишається редакторською.
- Цитата з оригіналом: перший рядок `>` — оригінал, другий `>` — переклад (в en.md, коли оригінал англійською, — без нього),
  останній `> — Хто · контекст`. Однорядкова цитата `> «…»[^cN]` теж допустима.
- Блоки в тексті: `:::tldr` … `:::` (список `- …` з виносками), `:::timeline` … `:::` (рядки `- дата | текст`).
  Ті самі блоки й `[[block:…]]` — в обох мовах.

### Фото (поле `media` у story.json)

```json
"media": [
  { "id": "m1", "role": "hero",
    "src": "/img/stories/spygate-2007/m1-1280.webp",
    "srcSet": "/img/stories/spygate-2007/m1-1280.webp 1280w, /img/stories/spygate-2007/m1-800.webp 800w, /img/stories/spygate-2007/m1-480.webp 480w",
    "width": 1280, "height": 853, "focus": "50% 40%",
    "credit": { "page": "https://commons.wikimedia.org/wiki/File:….jpg", "author": "…", "license": "CC BY-SA 4.0" },
    "caption": { "uk": "…", "en": "…" },
    "alt": { "uk": "…", "en": "…" } },
  { "id": "m2", "role": "inline", … }
]
```

- Файли — `public/img/stories/<slug>/<id>-<ширина>.webp` (hero: 1280/800/480; inline: 800/480), WebP якість ~75.
- Лише вільні ліцензії: CC BY, CC BY-SA, CC0, суспільне надбання (не NC, не ND); ліцензію й автора — з Commons API
  (`extmetadata`: `LicenseShortName`, `Artist`), не з тексту сторінки на око. Не логотипи як головний об'єкт.
- Фото — саме того, про що історія (та гонка/болід/людина/місце й рік); якщо такого немає — близьке за змістом
  з чесним підписом («Benetton B194 у музеї, 2015»). Підпис — фактичний, з опису файлу на Commons.
- Hero — щонайменше 960 px завширшки (краще ≥ 1280); inline — ≥ 640. 1–4 фото на історію.
- У тексті inline-фото ставиться окремим рядком `[[media:m2]]` (в uk.md і en.md — у тих самих місцях).
- Wikimedia: ОДИН процес, пауза між запитами, ≤ 3 повтори з урахуванням Retry-After.

## Правила

1. Кожне URL відкрито й перевірено (не з пам'яті). Немає в джерелі — немає в тексті.
2. Вікіпедія — не джерело, лише шлях до джерел (можна брати її виноски, перевіривши їх).
3. Результати гонок, кола, очки — можна з API Jolpica (`https://api.jolpi.ca/ergast/f1/…`), це наше джерело даних сайту.
4. Цитати — короткі (до ~40 слів), дослівно; довгі тексти чужих статей не копіювати (авторське право).
5. Цифри грошей — з роком і валютою; оцінки («близько», «за оцінкою X») так і подавати.
6. Мова: живо, без канцеляриту й штампів ШІ («варто зазначити», «не просто X, а Y», «у світі, де…»). Українська — сучасна
   спортивна: імена як на сайті (Льюїс Гамілтон, Міхаель Шумахер, Макс Ферстаппен).
7. Обсяг: історія 900–1 600 слів кожною мовою; топ технічних рішень — до 2 500.
8. Незалежність джерел — за видавцем: дві статті одного видання (або два документи FIA) — одне джерело, статус `one`.
9. У тексті — нічого понад джерела: жодних власних висновків («перша в історії», «більша частина покарання»),
   якщо їх немає в джерелі. Перевіряти «перший/єдиний/рекорд» на свіжість (рекорди б'ють).
10. Терміни як на сайті: Гоккенгайм, вікенд, паддок, машина безпеки, поулситер, піт-стоп, бокси (заїхав у бокси).
