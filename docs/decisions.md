# Рішення (ADR-лайт)

## 2026-11-10 · Next.js 16.4.5 замість 16.2.9
16.2.9 має critical-уразливість GHSA-673q-mjm6-r5xr, виправлену лише в 16.4.1+. Обрано 16.4.5 (містить ще 7 moderate-виправлень), а не 16.4.6 (вийшла за день до старту). Документація — з `node_modules/next/dist/docs/` встановленої версії. Деталі — `docs/audits/deps-phase1.md`.

## 2026-11-10 · Node ≥ 22.12
`engines.node: ">=22.12"` (у плані було `>=22`): Tailwind 4.3.4+ та частина інструментів потребують `require(esm)`, який увімкнено за замовчуванням з Node 22.12. Локально й у CI — Node 24 (`.nvmrc`).

## 2026-11-10 · React Compiler вимкнено
`create-next-app --no-react-compiler`: у плані фази 1 його немає; вмикати окремим рішенням після замірів.

## 2026-11-10 · `ignore-scripts=true`
У lock-файлі немає пакетів з install-скриптами; заборона закриває клас атак через `postinstall`. Браузери Playwright ставляться явною командою (`npx playwright install`), не скриптом.
