# Фаза 4a «Новини» — план (14.11.2026)

Сторінка `/news` (і `/uk/news`): заголовки трьох видань (RSS) і пости F1-журналістів у Bluesky. Еталон — макет
«Новини» v2 (https://claude.ai/artifact/4ciMrXVFq5m7j8hQevJGyU). Далі — фаза 4b «Головна» (бере той самий завантажувач).

## Рішення користувача 14.11
- Порядок: спершу новини (4a), потім головна (4b).
- Оновлення — ISR раз на 30 хв (як кеш Predictor), без cron.
- Bluesky — одразу (вкладки «Видання» / «Журналісти»).
- Головна (4b): лише блоки з живими даними; Історії / Новачкам / Гра — сховати до готовності розділів.
- Раніше (10.11): прев'ю новин лишаємо (посилання на оригінали картинок); Threads і X не беремо.

## Заміри 14.11 (факти)
- RSS: formula1.com `all.xml` — 200, 10 записів, **без pubDate і без картинок** (дата й og:image — зі сторінки статті,
  +10 запитів); Motorsport.com і Autosport — 200, по 50 записів, у всіх pubDate і `<enclosure>`; картинки з
  `cdn-1…9.motorsport.com` (обидва видання).
- Bluesky public API (`app.bsky.feed.getAuthorFeed`, `posts_no_replies`, без ключа): усі 11 акаунтів відповідають,
  останні пости 10–14.11. Один запит (adamcooperf1) раз повернув порожню відповідь, повтор — 200 → потрібні повтор і
  ізоляція помилок по джерелу.
- CSP сайту зараз `img-src 'self' data: blob:` — для прев'ю треба додати домени картинок видань.

## Дані — `src/lib/data/news.ts` (server-only)
- Джерела: formula1.com, Motorsport.com, Autosport (RSS); Bluesky: adamcooperf1, andrewbensonf1, chrismedlandf1,
  danielmoxon, elizablackstock, joesaward, keithcollantine, peterdwindsor, planetf1com (`.bsky.social`), racefans.net,
  rorymitchellf1.
- Кожне джерело — тайм-аут 8 с, один повтор, помилка одного не валить інші. `fetch(..., { next: { revalidate: 1800 } })`.
- formula1.com: og:image і `datePublished` (JSON-LD) зі сторінок статей, не більше 4 паралельно.
- Склейка дублів Motorsport/Autosport: Жаккар слів заголовка ≥ 0,5 → один запис з «Також: Autosport».
- Bluesky: лише власні пости (без репостів і відповідей), повага до мітки `!no-unauthenticated`, фільтр F1-слів
  (словник у коді + тест на знімку постів), посилання на `bsky.app/profile/<handle>/post/<rkey>`.
- Безпека: заголовки, анонси й пости — лише текст (теги прибрано, сутності розкодовано, React екранує); посилання — лише
  `https:` на домени джерел; картинки — лише з дозволених доменів, інакше без прев'ю.
- Усі джерела впали: під час ISR — кидаємо помилку (Next лишає попередню сторінку); під час збірки — порожній стан
  «Не вдалося завантажити» (збірка не падає).
- Тести: фікстури `e2e/fixtures/news/*` (знімки RSS і Bluesky 14.11); у unit/e2e завантажувач читає їх замість мережі
  (`NEWS_FIXTURES=1`), щоб прогони не залежали від чужих сайтів.
