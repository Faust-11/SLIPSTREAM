# Slipstream · Фаза 3f «Сторінка сезону» — план реалізації

> **For agentic workers:** Implement this plan task-by-task, checking off each step; verify each task before moving on. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/seasons/<рік>` і `/uk/seasons/<рік>` для кожного чемпіонату з 1950 року (77 сторінок) за макетом сезону 2025 https://claude.ai/artifact/VqJb88Tf4v5eEb5dJxwCka; рік на картках `/seasons` стає посиланням на сторінку сезону.

**Spec (макет 2025):**
1. **Крихти** — «← Усі сезони», сусідні сезони «‹ 2024» / «2026 ›».
2. **Банер** — фото на всю ширину, «Сезон 2025», один рядок підсумку: «Ландо Норріс виграв титул для McLaren з перевагою у 2 очки. Кубок конструкторів теж дістався McLaren.»
3. **Ключові числа (5)** — гонок, спринтів, різних переможців, очок між 1-м і 2-м, перемог команди-чемпіона з N.
4. **Битва за титул** — графік очок після кожного етапу (4 лінії: перші 4 у фінальному заліку; чемпіон — товща), легенда, смуга «лідер після кожного етапу», підказка на етапі; поруч — 3–4 абзаци з фактами (відрив, зміни лідера з діапазонами етапів, найбільше відставання й камбек, дискваліфікації).
5. **Троє претендентів** — картки перших трьох: фото, номер, місце («Чемпіон», «Друге місце»…), ім'я → пілот, команда → команда, очки (з відставанням), перемоги, поули, подіуми.
6. **Календар** — картка на етап: номер, дата, місто, Гран-прі, переможець (аватар, команда), поул, переможець спринту; позначка «S» для вікенду зі спринтом; смуга кольору команди переможця; вирішальна гонка виділена; примітки («Обидва McLaren дискваліфіковано»).
7. **Підсумкові таблиці** — пілоти (усі класифіковані, смуга очок, аватар, команда) і конструктори (з 1958).
8. **Сусідні сезони** — дві великі плитки з фото: «‹ Попередній сезон 2024 · Чемпіон: …», «Наступний сезон › 2026».

**Architecture:** як у 3b–3e. Числа — SQL: нові подання в міграції 0011 (у `f1.refresh_derived()`), один-два запити на сторінку, `generateStaticParams` — 77 років. Сторінка — серверна; графік — SVG на сервері (прецедент `team/season-chart.tsx`: підказка `<title>`, ті самі числа — у таблиці під графіком для клавіатури й екранних читачів), без клієнтського стану. Верстка — за настановами `modern-web-guidance` і конвенціями попередніх сторінок (довгі списки — `content-visibility: auto` із заміряною заглушкою, урок 3e).

## Global Constraints
- Усе з фаз 1, 3a–3e: бюджети Lighthouse (a11y/BP/SEO ≥ 95, performance ≥ 92, LCP < 2,5 с, CLS < 0.1, TBT < 400 мс), axe — 0 порушень в обох темах, CSP без змін, без логотипів, фото — лише вільні ліцензії Commons з авторами внизу, числа — лише з бази, розряди й множина за мовою.
- Правила підрахунку — чинні: старт — `f1.result_started` (0009), поул — `f1.v_pole` (`grid = 1`, не залежить від старту), очки заліку — офіційні (`driver_standings` / `team_standings` останнього етапу; у роки із зарахуванням кращих результатів — зараховані, не сума), титул і Кубок поточного сезону — лише коли математично вирішено, Кубок — з 1958, виключення — `adjustment_type` (Шумахер 1997, McLaren 2007).
- Ручного переліку винятків для гонок з повторним стартом не робимо (рішення користувача 12.11).
- Посилання лише на існуючі сторінки: пілоти, команди, сезони. Сторінок гонок і трас ще немає — картка етапу не посилання.
- Перевірки: під час розробки — unit, lint, typecheck, `db.yml` (чернетка PR одразу); повний пакет (e2e, незалежний рев'юер, `/code-review high` з URL PR і шляхом до репозиторію, UX-скриншоти 320–1440 у двох темах, Lighthouse) — один раз, коли сторінка готова. Пуш пакетами, коміти — Faust-11, у `main` — PR із зеленим CI, Rebase and merge за згодою. PR переводити в ready ДО останнього пушу.

## Рішення за прецедентами (без питань до користувача)
1. **Лінії графіка** — перші 4 фінального заліку (як у макеті); якщо хтось інший очолював залік хоч після одного етапу — додаємо його (смуга лідерів не має показувати пілота без лінії). Напарники однієї команди — той самий колір, другий — пунктиром (як у макеті).
2. **Поточний сезон (2026)** — графік і смуга до останнього етапу; «Лідер заліку» замість «Чемпіон», доки титул не вирішено; майбутні етапи в календарі — дата й місце без переможця; ключове число «очок між 1-м і 2-м» — на цей момент; банер — «Сезон триває: X з Y етапів».
3. **Вирішальна гонка** — перший етап, після якого титул математично вирішено (та сама логіка, що `v_driver_champion` 3e); для 2026 — лише якщо вже вирішено.
4. **Примітки на картці етапу — з даних:** дискваліфікація (status 20) пілота з першої трійки фінального заліку; скасований етап (`is_cancelled`); гонка з половиною очок (очки переможця < повних за системою сезону). Інших приміток — немає.
5. **Колір команди** — `seasons.json`/`teams.json` історичний колір; у тексті не використовуємо (контраст) — лише смуги, лінії, кружки.
6. **Indy 500 (1950–1960)** — етап чемпіонату в даних: у календарі є, у числі «гонок» рахується (як у 3e).
7. **Розмір сторінки** — HTML ≤ 100 КБ gzip; дані графіка — в SVG і таблиці, не в даних React.

## Рішення користувача 13.11
1. **Тексти «Битви за титул»** — автоматично з даних для всіх 77 сезонів (відрив, зміни лідера з етапами, найбільше відставання і камбек, дискваліфікації претендентів, зарахування кращих результатів, якщо воно змінило переможця); ручні редакційні абзаци для окремих сезонів — пізніше (адмінка, фаза 7).
2. **Фото** — наявні: банер — той самий файл Commons, що на картці сезону, широким кадром; претенденти — портрети пілотів (`driver-portraits.json`), без портрета — блок кольору команди з номером. Нові фото — адмінка.
3. **Обсяг** — усі 77 сезонів одразу одним шаблоном; розділи підлаштовуються під рік (без спринтів до 2021, без Кубка до 1958). Рік на кожній картці списку — посилання.

## Review Focus
1. Фінальні заліки всіх 76 завершених сезонів (перші 3 пілоти, очки) = Вікіпедія — тест на повний перелік; зарахування кращих результатів: 1988 (Сенна 90, Прост 87 зарахованих при 105 загалом), 1964 (Сертіз 40 / Гілл 39, загалом 41), 1950–1990.
2. Очки після кожного етапу: суми з `driver_standings` = накопичені результати гонок для 2021–2025 (крім років з корекціями), лідер після етапу — еталони 2025 (Норріс 1–4, Піастрі 5–19, Норріс 20–24), 2021 (рівні очки перед Абу-Дабі), 2010 (чотири претенденти).
3. Межові сезони: 1950 (Indy 500), 1997 (Шумахер виключений), 2007 (McLaren виключено з Кубка), 2016/2008 (титул в останній гонці), 2026 (триває), сезони з половиною очок (перелік звірити з даними: 1975 Іспанія й Австрія, 1984 Монако, 1991 Австралія, 2009 Малайзія, 2021 Бельгія).
4. Графік: доступний як `img` з описом + таблиця; 24 етапи на 320 px — горизонтальна прокрутка лише графіка, не сторінки; лінії не лише кольором (пунктир у напарників).
5. LCP — фото банера (`fetchpriority="high"`), решта фото lazy; CLS < 0.1; TBT — календар і таблиці з `content-visibility` нижче першого екрана.
