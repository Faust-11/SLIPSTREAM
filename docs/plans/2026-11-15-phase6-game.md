## Відхилення від макета (технічні, без зміни вигляду)
1. **Детермінізм між рушіями:** у `buildTrack` довжина відрізка рахується через `**2` (Math.pow), а специфікація JS не
  вимагає точного округлення pow — лише `+ − × ÷` і `sqrt`. Замінюю на `x*x`; unit-тест перевіряє, що бот і далі дає
  ті самі тіки (у V8 результат не зміниться — це гіпотеза, перевірю тестом; для Safari/Firefox — усуває ризик).
2. **Шапка, мова, тема — сайтові** (макет мав власні кнопки й localStorage `ss-lang`/`ss-theme`). Мова — посилання
  `/game` ↔ `/uk/game`; хеш траси (`#port`) при перемиканні мови зберігаю, якщо це не вимагає змін у спільному
  `lang-switch.tsx` (інакше — окремим пунктом у PR).
3. **Кадри — лише коли треба:** у макеті rAF малює сцену 60 разів/с завжди, навіть у «Готовий до старту?» і коли сцена
  поза екраном. Роблю: рендер на кожному кадрі лише у фазах «огні / заїзд / догальмовування»; у спокої — один кадр
  (і при зміні розміру); поза екраном (IntersectionObserver) і на прихованій вкладці — пауза. Менше TBT і батареї.
4. **React без перерендерів на кадр:** HUD (час, км/год, дельта, сектори) оновлюю через ref + `textContent`, React — лише
  для рідкісних станів (траса, фаза, результат, кола).
5. **Клавіші:** у макеті `C` (камера) спрацьовує будь-де на сторінці, стрілки перехоплюються сторінкою під час заїзду.
  Лишаю перехоплення стрілок лише в заїзді й `C`/`R`/Пробіл — коли фокус у грі.
6. Ключ localStorage `slipstream-hotlap-v2-<траса>` лишаю; міграцію з `…-v1` прибираю (макет жив на іншому домені —
  даних на сайті немає). Збережене коло перевіряється повтором: якщо час не збігся — рекорд відкидається (як у макеті).
7. `<noscript>`: гра потребує JS — коротке пояснення замість сцени.
