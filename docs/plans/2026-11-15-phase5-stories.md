## Рішення за прецедентами (без питань)
- Вибрана історія — Сузука-1989 (як у макеті), поле `featured` у story.json.
- Порядок карток — за роком (`years[0]`) від нових до старих; історії без року (розбори) — після, за назвою.
- Виноска — номери джерел (позиція в `sources`), кожен номер — посилання на `#s{n}`; статус — значок + прихований текст
  для читачів екрана (не лише `title`). Спливаюче вікно з твердженням — пізніше.
- Заголовок у двох рядках — розрізаємо за першим «: » (25 з 30 мають двокрапку); без двокрапки — один рядок.
- Рубрика в штампі — мітка категорії; за потреби поле `kicker` (uk/en).
- Час читання — `ceil(слова/140)` (замір макетів: 132–147 сл/хв).
- Факти банера (гонка, етап «N з M», дата, траса) — з бази за `links.races[0]` (або `race`); без гонки — рядок без них.
- Кредити фото — у підвалі сторінки (`<details>`, як у макеті й на інших сторінках сайту).
- Контраст (замір агента): лід на червоному — білий (3,41 → 4,70); акцентний рядок h1 у темній темі — світліший; значок «?» у темній
  темі — темний текст (2,33 → ≥ 4,5).
- Markdown — власний невеликий розбирач (абзаци, `##`, `>`, `**`, `*`, `[^cN]`, `[[media:mN]]`) у React-елементи, без сирого HTML.
  Нові блоки — лише формат: `:::tldr`, `:::timeline`, `[[block:bN]]` + `blocks` у story.json (рушій поки ігнорує невідомі блоки й
  чек-скрипт їх перевіряє).
- CSS-префікс `st-` (не `sr-`: збігається з `sr-only` Tailwind). Колір першого екрана — червоний Ferrari `#E8002D` (темна `#B8001F`), як у макеті.
