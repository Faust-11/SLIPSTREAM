# Slipstream · Фаза 3e «Сезони» (список) — план реалізації

> **For agentic workers:** Implement this plan task-by-task, checking off each step; verify each task before moving on. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/seasons` і `/uk/seasons` за затвердженим макетом https://claude.ai/artifact/B9DBEASjovLwLNhh8QN2tS — «стартова решітка» всіх чемпіонатів з 1950 року: найсвіжіший сезон на поулі, далі — у минуле, по одній «розмітці» на десятиліття.

**Spec (макет):** вступ (заголовок, абзац, три числа: сезонів, чемпіонів, найбільше титулів з іменами) → чипи десятиліть (якорі, активний — за прокруткою) → 8 блоків десятиліть: зліва назва десятиліття, підсумок («10 сезонів · 3 чемпіони», для поточного — «2026 триває») і перелік чемпіонів; справа — решітка карток у два зміщені стовпці. Картка сезону: фото чемпіона з роком, ім'я, команда, «7 перемог з 24 гонок», «Кубок: McLaren» (до 1958 — «Кубка конструкторів ще не було»); поточний сезон — лідер заліку, позначка «Сезон триває», «9 перемог · 20 з 23 етапів», Кубок — «оформлено», якщо вирішено. Унизу — автори фото.

**Рішення користувача 12.11:** фаза — лише список; сторінка сезону — наступна фаза. Картка поки не посилання на сезон (правило «без мертвих посилань»).

**Architecture:** як у 3b–3d. Числа — SQL (нове матеріалізоване подання `f1.season_index`, міграція 0010, у `f1.refresh_derived()`); один запит на збірку. Наш контент — `src/data/curated/seasons.json` (фото сезону: файл, автор, ліцензія, точка кадрування; колір команди чемпіона того сезону). Сторінка — серверна, без клієнтського стану; підсвітка активного чипа — малий клієнтський компонент (без JS чипи — звичайні якорі). Верстка — за настановами `modern-web-guidance` (рішення користувача 12.11) і конвенціями попередніх сторінок.

- Посилання лише на існуючі сторінки: ім'я чемпіона → сторінка пілота, команда → сторінка команди, Кубок → сторінка команди. Сторінок сезонів ще немає — рік не посилання.

Пуш пакетами, коміти — Faust-11, у `main` — PR із зеленим CI, Rebase and merge за згодою. PR переводити в ready ДО останнього пушу (інакше CI і Lighthouse пропускаються).

## Рішення за прецедентами (без питань до користувача)
1. **Фото сезонів** — 77 фото з опублікованого макета (`img/<рік>.jpg`, атрибуція — з його переліку): кожне звіряємо з Commons (ліцензія = атрибуція, вільна, не NC/ND), як портрети в 3c; розбіжність — фото не беремо. Розміри — WebP 2 ширини під картку. Без фото — портрет чемпіона (банер 3d) або блок кольору команди з ініціалами.
2. **Поточний сезон** — лідер заліку після останньої гонки, позначка «Сезон триває», «N перемог · X з Y етапів». Кураторське фото сезону прив'язане до пілота: якщо лідер змінився, а фото — іншого пілота, показуємо портрет нового лідера (не чуже фото).
3. **Колір картки** — колір команди чемпіона в тому сезоні з макета (історичні лівреї: Ferrari, Lotus, Brabham…) у `seasons.json`; у тексті колір не використовуємо (контраст) — лише смуга / рамка.
4. **Команда чемпіона** — команда, за яку він стартував у найбільшій кількості гонок сезону (правило `team_champions`, 3b); якщо дві — обидві через кому.
5. **Вступні числа** — з даних: сезонів (з гонками), різних чемпіонів (вирішені титули), найбільше титулів і всі пілоти з таким числом.
6. **Спільні чемпіони десятиліття** — у порядку від нових до старих, без повторів.

## Питання до користувача
Рішень, які мусить ухвалити користувач, не знайдено: макет затверджено, обсяг визначено. Якщо під час замірів даних з'явиться розбіжність (наприклад, фото з невільною ліцензією чи сезон без фото) — окремим списком після Task 2.

## Review Focus
1. Чемпіони й Кубки всіх 76 завершених сезонів = Вікіпедія (тест на повний перелік, не вибірка); перемоги чемпіона й кількість гонок сезону — вибірка еталонів (1950, 1958, 1976, 1988, 2004, 2021, 2023).
2. Межові сезони: 1950–1957 (Кубка немає), 2026 (триває; Кубок вирішено, титул — ні), 1970 (Ріндт — посмертний чемпіон), 1997 (Шумахер виключений — 2-й у заліку Френтцен), сезон з чемпіоном двох команд (1952 Аскарі — одна; 1994… перевірити даними).
3. Решітка: 320–1440 px без горизонтальної прокрутки, порядок читання й табуляції — від нових до старих попри візуальне зміщення стовпців; чипи десятиліть — якорі зі звичайною клавіатурною поведінкою; заголовки десятиліть — справжні `h2`.
4. LCP — фото першої картки (`fetchpriority="high"`, решта першого екрана — eager, далі lazy); 77 фото не блокують сторінку; CLS 0 (розміри в розмітці).
5. HTML ≤ 100 КБ gzip, жодних даних React для 77 карток (серверний компонент).
